# МотоГараж 🏍️

Мобільний застосунок для мотоциклістів українською мовою. Темна преміальна тема, неонові акценти, живі поїздки на карті, команди, друзі, трекінг маршрутів.

## Стек

- **React Native + Expo (SDK 51)** — кросплатформова розробка Android/iOS з однієї кодової бази.
- **react-navigation** — навігація нижніми вкладками.
- **react-native-maps + expo-location** — карта та геолокація в реальному часі.
- **Zustand** — легкий глобальний стан (гараж, друзі, поїздки).
- **Firebase** (Auth / Firestore / Storage / Cloud Messaging) — бекенд: авторизація (телефон/Google/Apple), синхронізація профілів і команд, зберігання фото, push-сповіщення.
- **moti + react-native-reanimated** — плавні анімації карток і кнопок.

## Що вже реалізовано (UI + логіка каркасу)

- Екран гаража з анімованими картками мотоциклів.
- Карта з відображенням користувача, фільтрами (всі/друзі/команда) та кнопкою видимості.
- Реальний GPS-трекінг поїздки: дистанція (формула гаверсинуса), макс./серед. швидкість, полілінія маршруту.
- Створення запрошень "Поїхали кататися" зі списком активних.
- Екран команд зі списком, детальною сторінкою та заглушкою чату.
- Екран друзів з пошуком, вкладками "Поблизу"/"Мої друзі", кнопкою QR.

## Що потрібно доробити перед продакшеном

1. **Авторизація** — підключити Firebase Auth (телефон, Google, Apple sign-in).
2. **Синхронізація в реальному часі** — Firestore-колекції `users`, `motorcycles`, `teams`, `invites`, `live_positions` (з TTL, щоб позиції зникали, коли людина вимкнула "Я катаюсь").
3. **Офлайн-кеш** — `expo-sqlite` для гаража та історії поїздок, читання без інтернету.
4. **Push-сповіщення** — Firebase Cloud Messaging + `expo-notifications` для запрошень і повідомлень.
5. **Завантаження фото** — вибір з галереї (`expo-image-picker`) + завантаження у Firebase Storage.
6. **Фонова геолокація** — `expo-location` `startLocationUpdatesAsync` для трекінгу, коли застосунок згорнутий.
7. **Світла тема** — перемикач у налаштуваннях, `lightTheme` вже описаний у `colors.ts`.

## Запуск

```bash
npm install
npx expo start
```

Далі — сканування QR-коду в Expo Go (для швидкого тестування) або збірка `eas build` для нативних Android/iOS білдів.
